# AI Resume Analyzer

An AI-powered Resume Analyzer that analyzes resumes, checks ATS compatibility, matches resumes with job descriptions, provides AI suggestions, generates interview questions, and creates professional resumes.
## Live Demo

Try the live application:

https://ai-resume-analyzer-s4byi5axfdeu6pmuuw5hpx.streamlit.app
## Features

- Resume PDF Upload
- Resume Quality Score
- ATS Score
- Skills Analysis
- Resume Structure Analysis
- Resume Formatting Analysis
- Project Quality Analysis
- Job Description Matching
- AI Resume Review
- AI Resume Rewriter
- AI Resume Section Editor
- Job-Specific Resume Optimizer
- AI Interview Questions Generator
- AI Mock Interview
- Final Resume Match Report
- Professional Resume PDF Generator
- AI Resume Builder
- Final AI Resume Dashboard

## Technologies Used
